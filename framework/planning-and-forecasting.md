# Planning and forecasting

Planning records work as a dependency-aware WBS. It distinguishes known work, assumptions, external dependencies, capacity constraints, risk exposure, and evidence required to close each item.

| Field | Meaning |
|---|---|
| Target Date | Desired date; may be aspirational. |
| Commitment Date | Date explicitly accepted by an accountable owner. |
| Forecast | Current evidence-based projection; include confidence and basis. |
| Actual | Date the event really occurred. |

Never populate a date or estimate without an input, an owner, or a stated assumption. When those are absent, use `TBD` and raise a SPEC-BLOCKER if the missing information prevents a safe commitment.
