# Engineering Execution Framework v0.x

The framework is born here as a versioned, reviewable operating model. It is not yet a Skill and it does not prescribe one toolchain for every project.

## Lifecycle

`Intake → Discovery → Framing → Design → Planning → Ready Gate → Execution → Verification → Convergence → Learning`

The lifecycle is adaptive: a low-risk change may collapse stages; high-uncertainty or high-impact work expands them. Skipping an artifact requires recording why the risk is still controlled.

## Core outputs

Project classification, problem statement, requirements, decision log, selected architecture views, NFRs, WBS/dependency plan, forecast fields, quality gates, traceability links, tests, and evidence.

See [`quality-gates.md`](quality-gates.md), [`planning-and-forecasting.md`](planning-and-forecasting.md), and [`traceability.md`](traceability.md).
