## Promotion rule
Knowledge Base material is not copied blindly. A rule enters this repository only when:
1. it is stated precisely;
2. its inputs/outputs are defined;
3. it has at least one project evidence example;
4. it does not depend on VECTOR-specific semantics;
5. its failure/stop behavior is explicit.
