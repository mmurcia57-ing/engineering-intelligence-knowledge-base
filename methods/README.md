# Methodological foundations

The framework treats methods as selectable capabilities, not a mandatory ceremony. A project first identifies uncertainty, risk, dependency density, reversibility, and evidence needs; then selects the lightest artifact set that makes the next decision safe.

Required method families:

- discovery and brainstorming;
- prioritization and decision framing;
- project planning, WBS, dependencies, capacity, and forecasting;
- SDD and implementation readiness;
- C4/arc42 and functional modeling;
- ADR/NFR and quality gates.
