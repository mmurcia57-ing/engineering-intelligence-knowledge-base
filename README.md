# Engineering Intelligence Knowledge Base

Versioned knowledge base for the Engineering Execution Framework.

## Scope

This repository consolidates research, primary-source references, working hypotheses, experiments, and decisions that feed Engineering Execution Framework v0.x. It is not the VECTOR repository and does not contain the Skill yet.

## Evidence discipline

Every material statement must be labeled as one of:

- `REFERENCE` — an external source or quoted model to inspect.
- `VERIFIED FACT` — checked against a primary source or repository evidence.
- `HYPOTHESIS` — plausible but not yet verified.
- `DECISION` — explicitly adopted project direction.

No label may be silently upgraded. Open questions remain visible in the relevant ledger.
