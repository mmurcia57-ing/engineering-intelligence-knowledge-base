Areas: knowledge graphs, temporal graphs, GraphRAG, entity resolution, agents, memory, MCP, Graphify, OpenTelemetry, Toise, agent observability, graph visualization, and self-hosted AI.

Selection rule: a technology enters an execution plan only when it solves a demonstrated problem better than a simpler alternative and its operational cost is understood.
