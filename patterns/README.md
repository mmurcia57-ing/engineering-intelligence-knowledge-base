# Patterns and anti-patterns

Patterns are recorded with context, forces, decision, consequences, evidence, and rollback conditions.

Initial hypotheses:

- **Evidence ledger:** one place for source, label, confidence, and open verification.
- **Decision freeze:** closed decisions remain stable unless a change trigger is recorded.
- **Progressive detail:** add artifacts only when uncertainty or risk justifies them.
- **Traceability spine:** link each requirement to decisions, executable work, code, tests, and evidence.
