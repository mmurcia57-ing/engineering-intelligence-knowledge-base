# Research and sources

Research notes must state the question, source, evidence label, finding, confidence, and implications for the framework. Primary sources are preferred: official specifications, project documentation, repositories, standards, and original papers.

Suggested areas:

- `methods/` — discovery, brainstorming, prioritization, planning, forecasting, SDD, WBS, gates.
- `architecture/` — C4, arc42, functional modeling, ADR, NFR.
- `intelligence/` — knowledge graphs, temporal graphs, GraphRAG, entity resolution, agents, memory.
- `observability/` — OpenTelemetry, agent observability, Toise.
